# MineSurvive

Survive the night. Gear up. Collect every mob.

A browser bullet-heaven / horde-survival fan game with a Minecraft aesthetic, a roguelike run structure and a gacha of companions. Built with Vite + TypeScript + Canvas 2D. See `docs/BRIEF.md` for the full design and build spec.
