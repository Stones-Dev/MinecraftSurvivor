## Sprites

All seven character sprite sheets (heroes, enemies, allies, animals, villagers) were created and uploaded by **Askywalker** on The Spriters Resource, in the Minecraft Customs collection (Custom / Edited section). The author allows their use with credit.

| Villagers (Undertale Overworld-Style) | https://www.spriters-resource.com/custom_edited/minecraftcustoms/asset/156322/ |

The sheets are sliced and packed by the tools in `tools/`; the source files stay untouched in `assets-src/`. The same credit appears in the game under About.

Version 1.1 added no new source pack. The extra mobs, animals, villagers and golems used by the new heroes, pets, allies and biome enemies (the lists in `tools/ship_heroes.json`, `tools/ship_companions.json` and `tools/ship_biome_mobs.json`) are cut from the Enemies, Allies, Animals and Villagers sheets above; every frame in `public/atlas/atlas.json` comes from one of these seven sheets (checked by frame-key prefix). Some sprite heroes are tinted or scaled in code. Terrain, block textures, props and icons are drawn in code and use no third-party art.

The End (v1.4) has no source art either: the Ender Dragon, the End Crystals and their iron cages, the obsidian pillars, the Dragon Egg, the End portal frame, the starfield and the end stone, bedrock and obsidian ground are generated by the game code (`src/render/endSprites.ts`, `src/world/endTiles.ts`) in the same blocky style as the props. This art is provisional and credits nobody; a hand-drawn set may replace it later.

The world structures (v1.4: villages, desert and jungle temples, trial chambers, pillager outposts, witch huts) have no source art either: their materials, props (chests, levers, cauldron, cage, crops, banners and the rest) and layouts are generated by the game code (`src/world/blocks.ts`, `src/world/props.ts`, `src/world/propSprites.ts`, `src/world/structureSprites.ts`, `src/world/structures/`). Their villagers, golem, pillagers, witch and other mobs reuse the Askywalker sheets listed above. The minimap icons for them are drawn in code too.

No AI-generated art is included in the game or its assets: apart from the Tiny5 font below, every pixel is either one of the seven credited sheets or drawn by code written for this project (terrain, blocks, props, icons, structures, the End, the Ender Dragon and the minimap icons).

## Font

Tiny5, Copyright 2022-2024 The Tiny5 Project Authors (https://github.com/Gissio/font_tiny5), licensed under the SIL Open Font License 1.1. Bundled as WOFF2 (Latin subset) in `public/fonts/` (the file comes from the `@fontsource/tiny5` npm package, which is not a project dependency) together with its licence, `public/fonts/OFL.txt`. The game rasterizes it once into a 1-bit glyph atlas at its native 8 px size.

## Audio

No audio files. All music and sound effects are generated at runtime with the Web Audio API; the compositions in `src/data/music.ts` are original.

## Code

MineSurvive's code is original work for this project (Vite, TypeScript, Vitest, ESLint and Prettier are used as build tooling only). The reference project named in the brief was read for ideas, not copied.
