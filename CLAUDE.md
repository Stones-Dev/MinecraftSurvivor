# MineSurvive

Browser bullet-heaven game (Vite + TypeScript + Canvas 2D). The full spec is `docs/BRIEF.md`: read it end to end before doing anything, and follow its working agreement, phases and checkpoints. Living docs live in `docs/` (GDD, PLAN, TASKS, DECISIONS, ASSET_CATALOG).

- Code, comments, UI and docs in English. Chat with the owner in Spanish.
- `assets-src/` holds the source sprite sheets (do not edit them). `assets-work/` and `reference/` are gitignored scratch folders.
- Stop at every CHECKPOINT in the brief and wait for the owner.
